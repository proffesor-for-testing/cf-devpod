# Deliberately Buggy Sites for Testing

Websites with intentional bugs, defects, and issues - perfect for exploratory testing, manual QA practice, and defect detection validation.

---

## Intentionally Buggy Applications

### AcademyBugs
- **URL**: https://academybugs.com/find-bugs/
- **What**: Mock e-commerce site with 25 real bugs planted inside
- **Features**: Bug examples page, bug types taxonomy, bug reporting practice, quiz after finding all bugs
- **Bug Types**: UI glitches, functional defects, layout issues, data inconsistencies
- **QE Use**: Exploratory testing training, defect classification, bug report quality

### QA Practice (Netlify)
- **URL**: https://qa-practice.netlify.app/
- **Bug Form**: https://qa-practice.netlify.app/bugs-form
- **What**: Testing playground with intentionally buggy forms, HTML elements, REST API, and GraphQL endpoints
- **Features**: Common web elements, buggy forms, e-commerce E2E flows, API testing
- **QE Use**: Multi-channel defect detection (UI + API), form validation testing

### Todo List with Bugs
- **URL**: http://todolist.james.am/#/
- **What**: Simple todo app with planted bugs
- **QE Use**: Functional testing, state management bugs

### Parking Calculator
- **URL**: https://www.shino.de/parkcalc/
- **What**: Simple parking cost calculator - "easy to understand in 5 minutes but has plenty of bugs"
- **QE Use**: Boundary value analysis, calculation logic testing, input validation

### Basic Calculator (9 Builds)
- **URL**: https://testsheepnz.github.io/BasicCalculator.html
- **What**: Interactive calculator with 9 different builds, each containing different bugs
- **QE Use**: Regression testing across builds, defect tracking, bug comparison

### Sweet Shop
- **URL**: https://sweetshop.netlify.app/
- **What**: Intentionally broken online store
- **QE Use**: E-commerce flow testing, payment logic, inventory bugs

### Restful Booker (API)
- **URL**: https://restful-booker.herokuapp.com/
- **What**: API with deliberate bugs in booking operations
- **QE Use**: API defect detection, contract violation discovery

## Exploratory Testing Challenges

### Black Box Puzzles
- **URL**: http://blackboxpuzzles.workroomprds.com/
- **What**: Puzzles that encourage exploratory testing techniques
- **QE Use**: Exploratory testing skills, hypothesis-driven testing

### QA Training Simulator (BugEater)
- **URL**: https://bugeater.web.app/
- **What**: Testing simulator for beginners with challenge list
- **QE Use**: Manual testing training, systematic exploration

### Evil Tester Practice Apps
- **URL**: https://testpages.eviltester.com/styled/index.html
- **What**: Collection of pages for practicing automation, exploratory testing, and JavaScript hacking. Each page has an About section with activity hints
- **QE Use**: Diverse testing challenges, technique practice

### CandyMapper
- **URL**: https://www.candymapper.net/
- **What**: Demo website for UI testing with focus on bug detection
- **QE Use**: Visual defect identification, UI regression

### Travel Agileway
- **URL**: http://travel.agileway.net/login
- **What**: Travel booking site for exploratory testing
- **QE Use**: Business flow testing, session-based testing
