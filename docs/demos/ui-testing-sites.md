# UI Testing Practice Sites

Sites designed for practicing web UI automation with Selenium, Playwright, Cypress, and similar tools.

---

## Top-Tier (Start Here)

### The Internet (Herokuapp)
- **URL**: https://the-internet.herokuapp.com/
- **Author**: Dave Haeffner
- **What**: Collection of common automation scenarios including checkboxes, dropdowns, drag-and-drop, dynamic loading, file upload/download, frames, hovers, infinite scroll, key presses, login, and more
- **Best for**: Beginners learning locators and element interactions
- **QE Use**: UI automation, element interaction testing, dynamic content handling

### Expand Testing Practice Site
- **URL**: https://practice.expandtesting.com/
- **What**: 50+ practice pages covering authentication, forms, dynamic tables, Shadow DOM, iframes, drag-and-drop, file operations, geolocation, plus built-in REST APIs
- **Includes**: Notes App (React), E-commerce Bookstore, BMI Calculator, Calorie Tracker
- **Best for**: Comprehensive automation practice across multiple frameworks
- **QE Use**: Full-stack testing (UI + API), framework comparison

### DemoQA
- **URL**: https://demoqa.com/
- **What**: Elements, forms, alerts/windows, widgets, interactions, and a Bookstore Application with API
- **Best for**: ToolsQA learning path, practicing complex widgets
- **QE Use**: Widget testing, form validation, API-backed UI testing

### Sauce Demo (Swag Labs)
- **URL**: https://www.saucedemo.com/
- **What**: E-commerce app with pre-configured logins (standard_user, locked_out_user, problem_user, performance_glitch_user, error_user, visual_user)
- **Best for**: Testing different user personas and edge cases
- **QE Use**: Login flows, cart management, checkout, visual regression

## Automation Playgrounds

### UI Testing Playground
- **URL**: http://uitestingplayground.com/
- **What**: Challenges around modern web automation pitfalls - dynamic IDs, AJAX, hidden layers, click interception, scrollbars, overlapped elements
- **Best for**: Handling tricky automation scenarios
- **QE Use**: Flaky test analysis, synchronization strategies

### QA Playground
- **URL**: https://qaplayground.dev/
- **What**: Focused challenges for specific automation skills
- **Best for**: Targeted practice on specific UI patterns
- **QE Use**: Framework capability assessment

### Tricentis Obstacle Course
- **URL**: https://obstaclecourse.tricentis.com/Obstacles
- **What**: Automation challenges with increasing difficulty
- **Best for**: Advanced automation skills
- **QE Use**: Automation maturity evaluation

### LambdaTest Selenium Playground
- **URL**: https://www.lambdatest.com/selenium-playground/
- **What**: Input forms, tables, drag-and-drop, JavaScript alerts, windows
- **Best for**: Selenium-specific practice
- **QE Use**: Cross-browser testing scenarios

### LetCode.in
- **URL**: https://letcode.in/test
- **What**: Element examples for end-to-end test automation
- **Best for**: Learning element locators and interactions
- **QE Use**: Locator strategy comparison

### Locator Game
- **URL**: https://testsmith-io.github.io/locator-game/
- **What**: Practice identifying optimal locators for elements
- **Best for**: Improving selector skills
- **QE Use**: Locator robustness testing

### Automation Camp
- **URL**: https://play2.automationcamp.ir/
- **What**: Automation skills playground with various challenges
- **Best for**: Intermediate to advanced automation
- **QE Use**: Framework stress testing
